# لوحة إدارة نبته

تطبيق Angular مستقل لإدارة متجر نبته. الواجهة عربية RTL ومتوافقة بصريًا مع واجهة المتجر الأساسية.

## التشغيل

```bash
npm install
npm start
```

ثم افتح `http://localhost:4200`.

## البناء

```bash
npm run build
```

## المسارات

- `/overview` النظرة العامة
- `/orders` الطلبات وتحديث حالتها
- `/products` المنتجات وحالة النشر
- `/inventory` تحديث المخزون
- `/customers` العملاء
- `/content` المقالات والرسائل والمراجعات
- `/settings` إعدادات المتجر والتنبيهات

## ربط Laravel

اللوحة متصلة بمسار `/api/v1` وتستخدم العقود الموثقة في المشروع الأساسي:

- `POST /auth/login` لتسجيل الدخول، دون أي مسار تسجيل عام للإدارة.
- `GET /me` لملف المستخدم الإداري الحالي.
- `GET /admin/orders` و`PATCH /admin/orders/{id}`.
- `GET /admin/products` و`PATCH /admin/products/{id}`.
- `GET /admin/customers`.

يُحفظ توكن الجلسة في `sessionStorage` فقط، ويُرسل مركزيًا من خلال HTTP interceptor. استجابة `401` تمسح الجلسة وتعيد المستخدم إلى تسجيل الدخول، واستجابة `403` تُعرض كرفض صلاحية.

لا توجد شيفرة Laravel داخل مساحة العمل الحالية، لذلك يجب أن يطبّق الخادم هذه المسارات وعقود الاستجابة وسياسات الصلاحيات الموضحة في `docs/api-contract.md`. الواجهة لا تعتبر إخفاء الأزرار بديلًا عن Laravel Policies.
